# searching-with-fff

Amp skill that searches the current git-indexed directory with [dmtrKovalenko/fff](https://github.com/dmtrKovalenko/fff).

```bash
amp skill add IceCodeNew/searching-with-fff
```

Pass `--global` to install under `~/.config/agents/skills/`.

[`searching-with-fff/SKILL.md`](searching-with-fff/SKILL.md) is how to search. [`searching-with-fff/mcp.json`](searching-with-fff/mcp.json) starts `fff-mcp` over stdio. Install `fff-mcp` with the upstream commands in the skill.
